# Windows 11 (WSL Ubuntu) Development Setup

Quick setup for my personal dev environment

## How to Run

```bash
# FIRST: Doenload this repo
cd <dev-env-setup>
chmod +x run.sh
./run.sh
```

Then restart your terminal.

## What Gets Installed

- apt
- Visual Studio Code
- Python 3
- Git
- Docker
- Miniconda

## Troubleshooting

If commands don't work after installation, restart your terminal.
